RESUMO HTML

1. O que é

Último Aurora que fizemos: site-anuncios/ rodando em https://workplace-offices-king-shortly.trycloudflare.com/index.html. Vitrine de anúncios adultos 18+ com busca por cidade, publicação com fotos, chat interno sem links, login com cookie.

2. Páginas HTML

index.html — Esplora / busca (q + citta) / Annunci recenti / gate 18+ (localStorage aurora18)
anuncio.html — Detalhe + contato via chat
publicar.html / editar.html — Criar / editar anúncio com até 5 fotos
chat.html — Messaggi / conversas
login.html / registrar.html / recuperar.html / reset.html — Auth + reset via Resend
dashboard.html — Meus anúncios + promo BENVENUTO
menu.js / dados.js (ANUNCI fallback) / styles.css — Menu mobile, seeds, CSS

3. Backend — server.js (Express :3003)

  • Static + /fotos (multer 5MB, só image/, 5 fotos)
  • Auth: /api/signup /login /logout /me — bcryptjs + cookie vetrina_session (sha256, 30 dias), rate-limit 15/15min
  • Anunci: GET /api/anunci (meus + SEED s1/s2/s3, destaque primeiro), POST/PUT/DELETE /api/anunci/:id (só dono)
  • Promo: POST /api/promo code BENVENUTO = 7 dias evidenza gratis
  • Chat: GET/POST /api/conversas, GET /api/conversas/:id, POST /api/conversas/:id/msgs — bloqueia links (LINK_RE), 1000 chars, seen/naolidas
  • Reset: /api/forgot /api/reset — token 1h, link /reset.html?token=, email via Resend
  • DB: data/vetrina.json {users, sessions, resets, anunci, conversas, promo}

4. Fluxo principal

Gate 18+ → guest-hero (Crea account gratis) → busca → card → anuncio.html?id= → login → contatta → chat.html → dashboard gerencia + promo.

5. Como rodar

cd ~/site-anuncios && npm start → http://localhost:3003/index.html → tunnel Cloudflare para URL pública.
